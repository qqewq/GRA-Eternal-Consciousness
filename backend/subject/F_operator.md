# Subject Assembler F (Оператор сборки субъекта)

**English:**
The function $F$ takes the swarm state and returns a unified conscious subject $S$:
\[
S = F(R, G, M, A)
\]
- $R$: current set of agents.
- $G$: global meta-goal (survival of consciousness).
- $M$: distributed memory (weighted sum of local memories, possibly with innate imprints).
- $A$: focus of attention (a dynamic subset of agents currently spotlighted).

Internally, $F$ uses the coordination protocol to fuse $R$ into a coherent ``self-model.'' The output $S$ is characterized by a first-person perspective, a temporal flow of qualia, and the illusion of continuity.

**Русский:**
Функция $F$ по состоянию роя возвращает единого сознающего субъекта $S$:
\[
S = F(R, G, M, A)
\]
Внутри $F$ использует протокол координации для слияния агентов в связную «модель себя». Результат – субъект с перспективой первого лица, потоком квалиа и иллюзией непрерывности.
