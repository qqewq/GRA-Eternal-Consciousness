# Agent Model (Модель агента)

**English:**
Each conscious subject is a swarm $R = \{a_1, a_2, \dots, a_N\}$ of distributed agents. An agent $a_i$ is a tuple $(m_i, c_i, g_i)$:
- $m_i$: local memory (episodic/semantic fragments).
- $c_i$: set of weighted connections to other agents.
- $g_i$: local sub-goal aligned with the global meta-goal $G$.

Agents continuously exchange information and adjust their sub-goals via a coordination protocol. The collective behavior of the swarm generates the emergent property of a unified subjective viewpoint.

**Русский:**
Каждый сознающий субъект представляет собой рой $R = \{a_1, \dots, a_N\}$ распределённых агентов. Агент $a_i$ – это кортеж $(m_i, c_i, g_i)$:
- $m_i$: локальная память,
- $c_i$: взвешенные связи с другими агентами,
- $g_i$: локальная подцель, согласованная с глобальной мета-целью $G$.

Агенты непрерывно обмениваются информацией и корректируют подцели по протоколу координации. Эмерджентным свойством роя является единый субъективный взгляд.
